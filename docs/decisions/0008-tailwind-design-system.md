# 0008 — Tailwind v4 design system on CSS variables

Date: 2026-10-18
Status: accepted

Supersedes the StyleX parts of [0001](0001-stack.md) (design system: coss/ui on
StyleX, `xstyle`, `base.css`), all of [0007](0007-interfere-design-system.md)
that concerns StyleX and `light-dark()` (its palette method, role names and
type scale carry over), and the EB Garamond wordmark in
[0002](0002-brand-typography-and-palette.md). The plan and the measured
reference are in `docs/design/`.

## Context

0007 adopted Interfere's design-system structure (design.interfere.com) on
StyleX and spent effort working around the engine: about 500 lines of scale
literals because StyleX needs build-time values, a browser floor of Chrome 123
/ Safari 17.5 for native `light-dark()`, and no descendant selectors, so
`base.css` keyed rules on `data-slot`. After the meeting copilot was stripped
(`docs/work/completed/strip-meeting-copilot.md`) the package held one primitive
and the web app one page, the cheapest moment to change engine.

## Decision

**Use the technique Interfere uses, not only its structure.** Tailwind CSS v4,
CSS-first (`@tailwindcss/vite`, no config file), Base UI primitives, and a
three-tier variable model:

1. **Scales** (`scales.css`, generated by `scripts/palette.ts`): Radix-style
   12 solid and 12 alpha steps per hue as `--brand-9`, `--gray-a3`, ... Light
   on `:root`, dark on `.dark` and on `prefers-color-scheme` unless `.light`
   pins light.
2. **Roles** (`theme.css`, `@theme static`): about 90 `--color-*` names
   (`page`, `component-hover`, `brand-solid`, `on-danger-solid-foreground`, ...)
   pointing at scale steps. Tailwind turns them into utilities. Default
   colors, radii, shadows, type sizes and fonts are cleared, so roles are the
   only colors that exist. `roles-dark.css` re-declares the roles whose dark
   value differs, and re-points text, borders and intent colors under
   `prefers-contrast: more`.
3. **Component variables** (`components.css`): `nm-btn` and its size, variant
   and shape classes set `--button-*`; the base class reads them. Variants are
   variables, never inline conditionals.

Tailwind's theme namespaces generate the type and weight helpers
(`text-heading-1..6`, `text-body-*`, `text-caption-*`, `text-code-*`,
`font-semimedium`) and the radius, shadow and easing utilities, so there is no
separate `utilities.css`.

### Choices that differ from the plan or from 0007

- **No `light-dark()`.** Roles are variables re-declared per mode, so the
  browser floor returns to Chrome 111 / Firefox 121 / Safari 16.4.
- **No separate Display P3 block.** The scales are OKLCH, which browsers
  gamut-map: wide-gamut displays render the full color, sRGB displays the
  nearest in-gamut one.
- **Alpha steps are derived, not authored.** Each is the most transparent
  color that composites to its solid over the mode's page (white; `oklch(15%)`
  in dark), so one role works on any surface. Solid ladders are OKLCH
  lightness and chroma arrays at one hue per scale, carried over from 0007's
  committed scales; the brand is one hue number. Scales are named by role
  (`brand`, `positive`, `warning`, `danger`, `info`, `gray`), not by the CSS
  color names 0007 used. 0007's `brandSurface` bands and the lavender blush and
  light pink scales are dropped until a page needs them.
- **Role mapping is 0007's**, including `info` and the brand focus ring
  reading alpha 9 in light (step 8 is the swatch, 2.2:1 on white; alpha 9 is
  5.7:1).
- **Fonts: Inter (OFL) only, plus the system monospace.** The wordmark is
  Inter semibold; EB Garamond is removed. Interfere's Heldane Text and
  Berkeley Mono files and its brand assets are licensed and never copied.
- **The theme classes belong on `<html>`**: a role resolves where it is
  declared, so a nested `.dark` would not flip roles it does not re-declare.
  The toggle (`features/theme`) and its pre-paint head script own them.
- **Primitives take `className` for layout only**; there is no class merging.
  Repeated geometry goes in `components.css`.

### Enforced by tests, not review

- `packages/ui/test/contrast.test.ts`: every text role against the surface it
  sits on, in light and dark, at WCAG AA (3:1 for the focus ring).
- `packages/ui/test/tokens.test.ts`: `scales.css` equals the generator's
  output; every color role resolves in both modes; the two dark blocks are
  identical; dark re-declares only roles that exist and differ; components read
  roles only and every variable they read is defined.
- `tooling/checks/structure.test.ts`: no other styling engine remains; app and
  primitive code names no scale step, literal or arbitrary color, and uses no
  `dark:` variant.

## Consequences

- Rewrote `Button` (variants `primary`, `secondary`, `tertiary`, `brand`,
  `danger`, `danger-subtle`, `transparent`, `link`, `link-brand`,
  `link-danger`; sizes `xs`..`xl`, default `md`; `shape`, `iconOnly`, `pending`)
  and the shell on it. `@stylexjs/*`, `@fontsource-variable/eb-garamond` and the
  `tokens.stylex` and `base.css` exports are gone; `@nomi/ui/styles.css` is the
  one stylesheet.
- Lost StyleX's typed, atomic, colocated styles. Long `has-[...]` / `*:[...]`
  class strings need discipline: put repeated geometry in `components.css`.
- New primitives port from coss/Base UI examples by reading, not by
  translating class names into another engine.
- Interfere's component internals were not in the page DOM (only the
  stylesheet and demo markup), so primitives are re-derived from demos.
- `feat/notebook-design-system` (Zodiak) and `feat/interfere-design-system`
  are separate explorations and are not part of this decision.
