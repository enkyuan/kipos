# Product

Ouro is an AI copilot for Forward Deployed Engineers (FDEs). This file
records only what exists, so nobody builds against an imagined product.

## Direction

An FDE's copilot in client meetings: it follows the conversation and keeps
the client's requirements and the implementation gaps that matter current
while the meeting runs.

## What exists

The base scaffold only: an API that answers `/health`, and a web shell whose
home page (`/`) shows the design kit (type, buttons, icons, avatars, motion)
that product screens are built from. No product feature is built.

## Who it is for

FDEs who work with clients and need an accurate, current picture of what the
client asked for.

## Non-goals (for now)

- Accounts, sign-in, or an authenticated surface.
